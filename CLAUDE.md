## Stack
- Expo SDK 53, React Native 0.79.6, React 19, old architecture (`newArchEnabled: false`), edge-to-edge.
- Single-file app: **`App.js`** (~1940 lines). It covers themes (brandTheme / darkTheme / lightTheme), glass UI with react-native-svg aurora, Manrope fonts, the keypad, and sheets: DealSheet, FxSheet, RegionSheet, DetailsSheet, ScanSheet.
- `data/regions.js`: 248 countries, 152 currencies, VAT for 107 countries. Generated by `scripts/gen-regions.js` (generator deps aren't runtime deps).
- OCR is on-device: `expo-text-extractor` (ML Kit); `parseOffer` turns offer-sign text into deal criteria.
- Exchange rates come from `open.er-api.com` (no key). They're cached in AsyncStorage `fx:<BASE>` and refreshed after 24 h or on Refresh, with an own rate per pair and per-pair confirmation.
- `plugins/withLegacyBack.js` sets `android:enableOnBackInvokedCallback=false`. Targeting API 36 enables predictive back, which bypasses RN 0.79's `onBackPressed`, so without this the Back swipe closes the app instead of the keypad.
- `app.json`: `expo-build-properties` sets compile/target SDK 36. `blockedPermissions` covers RECORD_AUDIO, SYSTEM_ALERT_WINDOW and WRITE_EXTERNAL_STORAGE.

## CI (GitHub Actions)
- `test-apk.yml`: every push to `claude/**` builds a debug-signed release APK and publishes pre-release `test-<shortsha>`. Download URL: `https://github.com/SamerGM/discount-calculator/releases/download/test-<sha>/shopping-calculator-test-<sha>.apk`. Gradle sometimes fails fetching from Maven (transient); re-run the job.
- `build.yml`: a push to `main` bumps `versionCode` and builds the signed Play AAB.
- In cloud sessions `gh` GraphQL is blocked. Use `gh api repos/SamerGM/discount-calculator/...` (REST).

## Preview tips
- Web preview needs `react-dom@19.0.0 react-native-web@~0.20.0 @expo/metro-runtime@~5.0.5`. Install them with `--no-save` in the scratch worktree only, not in the repo's package.json.
- `CI=1 npx expo start --web --port 8099 --clear`. CI mode doesn't watch files, so restart after edits.
- Mock rates in Playwright with `ctx.route('**/open.er-api.com/**', …)`. First launch shows the "Where are you shopping?" sheet: pick a country, then "Save as default".
